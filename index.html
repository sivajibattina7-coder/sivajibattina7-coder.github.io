The problem

Business users wanted answers from their data, but getting them meant: Business Question → Analyst → SQL → Validation → Result. That created a hard dependency on technical teams and slowed down even simple questions.

The challenge: can we let business users ask questions in natural language while keeping SQL generation reliable?

My role & approach

AI Product Lead, Founders Office — owned product strategy, problem definition, user workflows, AI architecture, RAG / knowledge design, roadmap, engineering collaboration, evaluation, and customer deployment for Friday AI (a text-to-SQL & BI product), a real-time Tally connector, and a voice-agent MVP for the Telangana Power Department.   • Led development of an AI-powered analytics platform using NLP, RAG, and metadata, enabling instant database querying and dashboard creation with ~85% accuracy across SAP, Shopify, Google Analytics, and Meta datasets for 10+ clients.

The key insight

"AI product quality is often a context problem, not simply a model problem." Better generation needed better context — so the product evolved from LLM → SQL to Question → Relevant Context → Schema → SQL → Validation → Answer.

02 — HOW I BUILD

A simple loop, run every time.

Problem → Understand → Define → Build → Measure → Iterate. Then back to the top.

01 / FIND THE PROBLEM

Understand what's broken

Before jumping to a solution, get specific about what's actually failing today.

02 / UNDERSTAND THE USER

Who feels the pain

Who experiences this? What are they doing today, and what makes it painful?

03 / DEFINE SUCCESS

Make it measurable

Translate the problem into a user metric, a product metric, and a business metric.

04 / BUILD THE SIMPLEST FIX

Prototype fast

Use AI, no-code, code, and existing infrastructure — whatever gets to a real test fastest.

05 / SHIP & MEASURE

Track real behaviour

Ship it, then check whether behaviour actually changed — not just whether it shipped.

06 / ITERATE

Feed it back in

Use data and user feedback to decide what to fix next — and the loop runs again.
